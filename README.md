# 🎓 Student Management System

A simple **Java-based console application** for managing student records using **JDBC** and a **MySQL database**. This project allows users to add, delete, update, and view student information interactively through the command line.

---

## 📌 Features

- Add new student records
- Delete students by ID
- Update existing student details
- View all student records
- Simple, menu-driven CLI interface

---

## 🛠️ Technologies Used

- Java
- JDBC (Java Database Connectivity)
- MySQL
- MySQL Workbench (for database management)
